> **Problem:** Extracting accurate, cited answers from multiple PDFs at scale with low latency.

`FastAPI` `LangChain` `FAISS` `Llama-3-70B (Groq)` `Cohere Embeddings` `Next.js`

- 📈 Retrieval accuracy: **68% → 84%** (validated on 150 real-world queries)
- ⚡ Latency: **3.1s → 1.5s** via Groq inference + async FastAPI + embedding caching
- 🛡️ Citation grounding + fallback responses to mitigate hallucinations
- 🔧 Pipeline: PDF ingestion → 800/150-token chunking → embeddings → FAISS → MMR retrieval → LLM synthesis
